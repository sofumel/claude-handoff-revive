# Known-prefix secret detection patterns — SINGLE SOURCE for both
# sanitize-handoff.sh and sanitize-handoff.ps1 (one regex per line, '#' for
# comments). Every pattern must be valid in BOTH POSIX ERE and .NET regex.
#
# Detection is deliberately conservative (prefix-based): false negatives are
# documented (generic passwords, unprefixed random strings), false positives
# are kept rare. Contributions of new well-known prefixes are welcome.
#
# OpenAI / Anthropic style keys
sk-[A-Za-z0-9_-]{16,}
# Google API keys
AIza[0-9A-Za-z_-]{30,}
# GitHub tokens (classic + fine-grained families)
gh[pousr]_[A-Za-z0-9]{30,}
# Slack tokens
xox[baprs]-[A-Za-z0-9-]{10,}
# AWS access key IDs
AKIA[0-9A-Z]{16}
# PEM private key headers
-----BEGIN [A-Z ]*PRIVATE KEY-----
# JWTs (header.payload prefix)
eyJ[A-Za-z0-9_-]{20,}\.[A-Za-z0-9_-]{10,}
